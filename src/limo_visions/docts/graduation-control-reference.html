graduation_control.py 结构与流程

巡线控制节点 graduation_control：根据检测结果控制阿克曼小车沿左侧黄线行驶。每帧先按黄线状态选出基础转向（PD / 缺口直行 / 丢线搜索），再经过盲区防压线保护修正，限幅后发布到 /cmd_vel。

341代码行数
0.19 m/s巡航速度（恒定）
3 → 1订阅 / 发布话题
0.4 s看门狗超时

每帧决策流程（pose_callback）

线速度在所有分支都是 cruise_speed，只有角速度不同。

数据流

只有看到黄线（x ≥ 0）且已有里程计时，才把目标点记入 line_memory。右侧点在 right_callback 中加锁写入，_limit_turn 读取时也加锁复制。

巡线决策详解

_update_line_state：丢线判断

line_ending  = far_row >= 298 and 0 <= x <= 115
line_missing = z <= 5 or x < 0 or line_ending
just_recovered = not line_missing and prev_line_missing
lost_frame_count = lost_frame_count + 1 if line_missing else 0

快到缺口（line_ending）：缺口前黄线末端向左外弯，跟踪到的最远端行号变大（正常约 241，缺口前约 300），列坐标落在目标列左侧。此时不再跟随列坐标，否则车会斜着冲过缺口并压线。

右转弯时最远端行号同样会变大（约 280–301），但列坐标在目标列右侧，所以不会被误判为缺口。

_base_turn：三个分支

if line_missing:
    if lost_frame_count <= 60:
        return 0.0                 # 缺口直行
    return -0.38 if y <= 340 else 0.0   # 搜索
error = 115 - x
derivative = 0 if just_recovered else error - prev_error
prev_error = error
return 0.007 * error + 0.0 * derivative
分支条件角速度原因
PD 巡线看到黄线kp·误差 + kd·变化黄线保持在第 115 列
缺口直行丢线 ≤ 60 帧0按缺口前车头方向开过缺口（约 43 帧）
右转搜索丢线 > 60 帧，y ≤ 340−0.38顺时针赛道缺口后向右；停车无法转向
直行丢线 > 60 帧，y > 3400车身正对黄线

盲区防压线保护

为什么需要
相机最近只能看到车前约 0.95 m。按目标列转向相当于瞄着前方约 1 m 的点，弯道处会提前转向切弯：左拐时左侧车身压到左线拐角（顶部凸起），右拐时右侧车身扫到内侧线端（右下角）。仅调 target_x 或延迟转向都无法解决。

1. 记忆：相机看到黄线时，把地面点按当前里程计位姿换算到里程计坐标系存下来；车开进盲区后仍然知道黄线在哪里。

2. 当前净距：_clearance 只看检查窗口内、位于该侧的记忆点，取最小横向距离减去车身半宽 0.20 m。

3. 预测：_predicted_clearance 按候选角速度（截断到 ±0.4）绕后轴积分 15 步 × 0.1 s，记录途中两侧的最小净距。

4. 选择：要求左侧 ≥ min(0.25, 当前左净距)、右侧 ≥ min(0.15, 当前右净距)，即已经小于要求的一侧只要求不再更近。候选从期望值出发按 0, +0.05, −0.05, +0.10… 由近到远检查，取第一个满足的；都不满足时取总缺口最小的。

效果：拐角处车先直行，让车身越过拐角再转；车头背离黄线的方向不受限制，可以正常回正。

按后轴积分是因为阿克曼车身绕后轴转动，后轴不会横向甩出；用 0.4 rad/s 上限是因为 0.19 m/s 下底盘实测右转最快约 0.4、左转约 0.25，指令再大也转不动。这两点修正前，保护会高估转向能力，车在弯后左右摆动。

可调参数

全部可以用 ROS 私有参数覆盖，例如 rosrun limo_visions graduation_control.py _target_x:=120。私有参数会留在参数服务器上，恢复默认前要执行 rosparam delete /graduation_control。各参数所在行号见《巡线参数调整手册》。

安全机制

机制行为
启动保护第一次检测到黄线（x ≥ 0）前一直发零速
看门狗每 0.1 s 检查一次，超过 0.4 s 没收到检测消息就发零速
退出Ctrl+C 时连续发 5 次零速（time.sleep，仿真时钟停止也能退出）
不停车搜索持续丢线时保持前进，阿克曼底盘停车无法转向
角速度限幅所有指令发布前限制在 ±0.8 rad/s
